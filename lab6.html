Лабораторна робота № 6 · Чисельні методи

Чисельне розв'язування диференціального рівняння

Усі приклади побудовано на рівнянні зі зразка звіту. Результати свого варіанта отримайте власною програмою та порівняйте, чи спостерігаються ті самі ефекти.

1. Що таке диференціальне рівняння

У звичайному рівнянні невідоме — число: x + 3 = 5, отже x = 2. У диференціальному рівнянні невідоме — функція, а задано правило, за яким обчислюється її швидкість зміни (похідна).

dy/dx = −0,6 · y,   y(0) = 0,3

dy/dx — швидкість зміни y; −0,6·y — якою вона має бути: що більше y, то швидше воно зменшується. Сама швидкість заздалегідь не відома — її обчислюють із поточного значення y:

y0,30,20,10
швидкість −0,6·y−0,18−0,12−0,060

Правило задовольняє безліч функцій. Початкова умова y(0) = 0,3 вказує, звідки починається розв'язок, і вибирає з них одну.

Знайти функцію можна двома способами. Аналітично — формулою; це можливо лише для простих типів рівнянь. Чисельно — кроками (Ейлер, Гюн, Рунге — Кутта); це можливо для будь-якого рівняння, але результат наближений. У роботі використовуються обидва способи: формула дає точні значення, з якими порівнюються чисельні методи.

2. Аналітичний розв'язок (п. 2 звіту)

Рівняння зразка розв'язується розділенням змінних.

Крок 1. Перенесіть y і x у різні частини рівняння (поділіть на y, помножте на dx):

dy / y = −0,6 · dx

Крок 2. Проінтегруйте обидві частини: ∫ 1/y dy = ln y, ∫ −0,6 dx = −0,6·x. Стала c з'являється, бо похідна сталої дорівнює нулю:

ln y = −0,6·x + c

Крок 3. Позбудьтеся логарифма (якщо ln y = a, то y = ea) і позначте ec = C:

y = e−0,6x + c = ec · e−0,6x = C · e−0,6x

Це загальний розв'язок — уся множина функцій, по одній для кожного C.

Крок 4. Початкова умова визначає C: y(0) = C · e0 = C = 0,3.

y = 0,3 · e−0,6x

Завдання: розв'яжіть так само рівняння свого варіанта.

3. Поле напрямків

За правилом dy/dx = −0,6·y поводяться ліки в крові, радіоактивний розпад, розряд конденсатора.

У кожній точці (x; y) рівняння задає нахил — намалюємо його маленькою рискою. Вийде «течія». Розв'язок — крива, що пливе за течією. Клацніть на графіку в будь-якій точці — від неї попливе ще один розв'язок.

Завдання: запустіть кілька розв'язків з різних точок. Чи перетинаються криві? Що відбувається на осі y = 0? Яку роль тоді відіграє початкова умова y(0) = 0,3?

Одне рівняння має безліч розв'язків — по одному через кожну точку. Початкова умова вибирає з них один. Точний розв'язок зразка — y = 0,3·e−0,6x; для більшості рівнянь такої формули немає, і криву будують чисельно.

4. Метод Ейлера: як він працює

Відома лише одна точка — початкова: x = 0, y = 0,3. Відрізок [0; 1] ділять на N = 20 кроків довжиною h = (1 − 0) / 20 = 0,05 і проходять його крок за кроком.

Один крок методу:

k = f(x, y)   — похідна в поточній точці (з рівняння: k = −0,6·y)
y := y + k·h  — нове y = старе y + похідна × крок
x := x + h

Рівняння dy/dx = −0,6·y — це правило для похідної в будь-якій точці; k — її значення в поточній точці, тобто нахил дотичної. Метод вважає, що протягом усього кроку похідна така сама, як на його початку, і рухається вздовж дотичної (як метод Ньютона в ЛР5; зв'язок з ЛР3: похідна ≈ Δy / h, отже Δy ≈ похідна · h).

Метод Ейлера весь час дає значення нижче точних, і похибка зростає: 0,00013 після першого кроку, 0,0015 у кінці. Причина: похідна береться на початку кроку, коли y найбільше і спадає найшвидше; протягом кроку y зменшується, і справжня швидкість стає меншою. Похибки окремих кроків накопичуються.

У програмі зразка крок методу — три рядки в циклі; функція fun(x, y) — права частина рівняння:

for i in range(1, n + 1):
    k1 = fun(x, y)
    y = y + k1 * h
    x = x + h

У рівнянні зразка права частина не залежить від x, але fun приймає і x, і y: загальний вигляд рівняння — dy/dx = f(x, y). Тому ті самі методи працюють для будь-якого рівняння — змінюється лише fun.

5. Метод Гюна: середня похідна початку й кінця кроку

Метод Ейлера бере похідну лише на початку кроку і тому відстає. Метод Гюна визначає похідну і на початку, і в кінці кроку, а крок робить із їхнім середнім.

Один крок методу:

k1 = f(x, y)   — похідна на початку кроку
y + h·k1   — пробний крок Ейлером: наближене y в кінці кроку
k2 = f(x + h, y + h·k1)   — похідна в кінці кроку
y := y + (k1 + k2) / 2 · h
x := x + h

Пробне значення y + h·k1 — це ще не похідна, а значення y в кінці кроку, обчислене методом Ейлера. Воно потрібне лише для того, щоб підставити його в рівняння й отримати похідну k2. Потім крок виконується заново — із середньою похідною.

На кінці відрізка (x = 1, N = 20) похибка методу Ейлера — 0,0015, методу Гюна — 0,000015: у 100 разів менша, хоча на кожному кроці обчислюється лише дві похідні замість однієї.

У програмі зразка:

k1 = fun(x, y)

Зв'язок з ЛР3: метод Ейлера подібний до методу лівих прямокутників (значення лише на лівому краї), метод Гюна — до методу трапецій (середнє двох країв).

6. Метод Рунге — Кутта: чотири похідні на крок

Метод Рунге — Кутта продовжує ту саму ідею: похідну визначають у кількох точках кроку й беруть середнє.

МетодПохідних на крокДе
Ейлер1на початку
Гюн2на початку і в кінці
Рунге — Кутта4на початку, двічі в середині, у кінці

Один крок методу:

k1 = f(x, y)   — похідна на початку
k2 = f(x + h/2, y + k1·h/2)   — пробні пів кроку з k1: похідна в середині
k3 = f(x + h/2, y + k2·h/2)   — ще раз пів кроку, з k2: уточнена похідна в середині
k4 = f(x + h, y + k3·h)   — повний пробний крок з k3: похідна в кінці
y := y + (k1 + 2·k2 + 2·k3 + k4) / 6 · h
x := x + h

Як і в методі Гюна, пробні кроки дають лише значення y, у яких обчислюється похідна; кожен наступний пробний крок використовує уточнену похідну з попереднього. Середина має вагу 2 (ваги 1, 2, 2, 1, сума 6).

Усі три методи мають складність O(N) — відрізняється лише сталий множник (1, 2, 4). Натомість при подвоєнні N похибка зменшується в 2, 4 і 16 разів відповідно, тому за однакову точність метод Рунге — Кутта найдешевший. На практиці використовують саме його.

У програмі зразка:

k1 = fun(x, y)
k2 = fun(x + h / 2, y + k1 * h / 2)
k3 = fun(x + h / 2, y + k2 * h / 2)
k4 = fun(x + h, y + k3 * h)
y = y + (k1 + 2 * k2 + 2 * k3 + k4) * h / 6
x = x + h

Зв'язок з ЛР3: ваги 1, 2, 2, 1 — це формула Сімпсона (1 : 4 : 1), у якій середня точка врахована двічі (4 = 2 + 2).

8. Де застосовують диференціальні рівняння

Майже всі закони природи записано як правила зміни. Формулою розв'язується мала частина; решту обчислюють кроками — як у цій роботі.

Медицинаорганізм виводить частку ліків за годинуконцентрація в крові, коли давати наступну дозу
Електронікаструм конденсатора ∝ швидкості зміни напругинапруга в колі від часу

Епідеміологіянові хворі ∝ контактам хворих зі здоровимикількість хворих від часу
Прогноз погодирівняння руху й нагріву повітрятемпература, тиск, вітер у кожній точці

Фізика в іграх

Ігровий рушій кожен кадр (60 разів за секунду) робить саме крок методу Ейлера або подібного: швидкість := швидкість + прискорення·h, положення := положення + швидкість·h, де h = 1/60 с. Формули траєкторії ніхто не шукає — правило зміни виконується кроками.

Прогноз погоди

Атмосферу ділять на сітку точок і для кожної крок за кроком розв'язують рівняння руху й теплообміну. Це ті самі чисельні методи, лише рівнянь — мільйони, тому прогноз рахують суперкомп'ютери.

Детальніше і дуже наочно — урок 3Blue1Brown «Differential equations, studying the unsolvable» (англійською, є субтитри).

Висновки

  • Диференціальне рівняння задає не функцію, а правило її зміни; початкова умова вибирає один розв'язок із безлічі.
  • Чисельний метод іде за правилом кроками: Ейлер — по нахилу на початку кроку, Гюн і Рунге — Кутта — по усереднених нахилах.
  • Менший крок — менша похибка; що вищий порядок методу, то швидше вона зменшується.

Перевірте на своєму варіанті: у скільки разів похибки трьох методів відрізняються при N = 20? Як змінюється абсолютна похибка Ейлера вздовж x?
