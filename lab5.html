Лабораторна робота № 5 · Чисельні методи

Розв'язування нелінійного рівняння: метод половинного ділення і метод Ньютона

Усі приклади побудовано на рівнянні зі зразка звіту. Результати свого варіанта отримайте власною програмою та порівняйте, чи спостерігаються ті самі ефекти.

1. Нелінійне рівняння

Нелінійнеусе, що не лінійне: x³ − 2 = 0, cos x = x, e−x = 0,5кривазагальної формули немає → чисельні методи

Квадратне рівняння — окремий випадок нелінійного. У зразку

f(x) = x² + 0,3x − 0,18 = 0

Точні корені (через дискримінант D = 0,81): x₁ = −0,6, x₂ = 0,3. Програма шукає додатний корінь двома чисельними методами; точна відповідь потрібна, щоб перевірити, наскільки вони до неї наближаються.

Корінь рівняння — точка, де графік f(x) перетинає вісь x. Обидва методи шукають цю точку кроками, використовуючи лише значення f (і для Ньютона — похідну f′(x) = 2x + 0,3).

2. Метод половинного ділення (бісекція)

Якщо на кінцях відрізка [a; b] функція має різні знаки, графік мусить перетнути нуль між ними. Беремо середину c = (a + b)/2 і лишаємо ту половину, де знаки на кінцях досі різні. Так само грають у «вгадай число»: кожна відповідь «більше / менше» відкидає половину варіантів.

Завдання: виконайте кілька кроків на відрізку зразка. У скільки разів зменшується відрізок за крок? Оберіть [−1; 1] — чому метод не може почати, хоча коренів на відрізку два?

Графік щоразу наближується до поточного відрізка. Відрізок довжиною 0,35 після 32 поділів стає коротшим за 10⁻¹⁰ — тому в консолі зразка рядки 0…32. Кількість кроків відома наперед і майже не залежить від ширини відрізка: [0; 1] — 34 кроки.

3. Метод Ньютона

У поточній точці x проводимо дотичну до графіка — пряму з нахилом f′(x). Наступне наближення — точка, де дотична перетинає вісь x:

xₙ₊₁ = xₙ − f(xₙ) / f′(xₙ)

Звідки формула: дотична y = f(xₙ) + f′(xₙ)·(x − xₙ); прирівнюємо y = 0 і виражаємо x. Біля точки дотику дотична майже збігається з кривою, тому її нуль близький до кореня.

Завдання: зі старту зразка x₀ = 0 перший крок «перестрибує» корінь. Чому? Порівняйте старти −0,15, −0,14 і −1: що відбувається і чому?

Ньютон потребує похідної та стартової точки поблизу кореня. Якщо дотична майже горизонтальна (біля вершини параболи), наступна точка відлітає далеко; якщо f′ = 0 — ділення на нуль. Зі старту лівіше вершини метод знаходить інший корінь, −0,6.

4. Порівняння швидкості

Відстань поточного наближення до кореня 0,3 після кожного кроку (шкала логарифмічна: кожна поділка — у 100 разів менше).

На практиці методи поєднують: спершу грубо визначають проміжок, де корінь (графік, таблиця значень, бісекція), потім швидко уточнюють Ньютоном.

Давач температури PT100

Опір платинового давача зростає з температурою: R(T) = 100·(1 + 3,9083·10⁻³·T − 5,775·10⁻⁷·T²) Ом (стандарт IEC 60751, для T ≥ 0 °C). Прилад вимірює опір, а показати треба температуру — тобто розв'язати квадратне рівняння відносно T. Для R = 138,51 Ом: T ≈ 100,0 °C; другий корінь ≈ 6668 °C фізичного змісту не має — так само, як у роботі обирають лише додатний корінь.

Квадратний корінь методом Ньютона

Для рівняння x² − 2 = 0 формула Ньютона спрощується до xₙ₊₁ = (xₙ + 2/xₙ)/2 (метод Герона, відомий з античності). Від x₀ = 1: 1,5 → 1,41667 → 1,414216 → 1,4142135624 = √2. Чотири кроки — і всі цифри правильні.

Висновки

  • Нелінійні рівняння в загальному випадку не мають формули розв'язку; корінь знаходять ітераційно — кроками, поки зміна не стане меншою за задану точність.
  • Половинне ділення надійне, але повільне: відрізок зменшується вдвічі за крок.
  • Метод Ньютона швидкий (цифри подвоюються), але потребує похідної і доброго старту.
  • Обидва методи спершу потребують грубої оцінки, де корінь: відрізка з різними знаками або стартової точки поблизу.

Перевірте на своєму варіанті: скільки рядків бісекції у вас вийшло і чому саме стільки? За скільки ітерацій зійшовся Ньютон? Чи збігається знайдений корінь з обчисленим через дискримінант?

  4. Чому перший крок методу Ньютона з вашої стартової точки опиняється саме там? Покажіть на графіку з дотичною.
  5. Що станеться з методом Ньютона, якщо стартувати з вершини параболи? А трохи поруч із нею? А лівіше від'ємного кореня? Спершу передбачте.
