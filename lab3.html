Лабораторна робота № 3 · Чисельні методи

Чисельне визначення похідної та інтеграла

Усі приклади побудовано на функції зразка звіту. Для свого варіанта підставте власні A і k.

1. Функція

У кожному варіанті функцію задано формулою

f(x) = A · e−k·x

A залежить від групи, k — від номера варіанта. У зразку A = 1, k = 0,189: f(x) = e−0,189x.

Це показникова функція y = A · ax (a > 0, a ≠ 1): змінна x стоїть у показнику степеня. Оскільки e−kx = (e−k)x, основа a = e−k < 1, тому функція спадає.

Зразокa = e−0,189 = 0,8278: на кожній одиниці x значення зменшується на ≈ 17 %

2. Завдання

  1. Похідна в точці x = 0 — швидкість зміни функції на початку.
  2. Інтеграл від 0 до ∞ — площа під усією кривою.

Кожну величину визначають двічі: аналітично (точне значення за формулами) і чисельно (програмою, лише за значеннями f у точках). Порівняння показує похибку чисельного методу.

На практиці формули часто немає: є записи датчика або програма, що обчислює f(x). Тут формулу відомо навмисно — щоб виміряти похибку.

3. Різницеві формули похідної

Для знаходження похідної в точці x програма використовує дві різницеві формули:

df/dx1 = (f(x + h) − f(x − h)) / (2h)
df/dx2 = (−f(x + 2h) + 8f(x + h) − 8f(x − h) + f(x − 2h)) / (12h)

h — крок. Похідну обчислюють при x = 0 для h = 1; 0,1; 0,01; … ; 10−16 і порівнюють з точним значенням.

Різницева формула наближено обчислює похідну через значення функції в кількох сусідніх точках, віддалених на крок h.

Чому так: похідна — нахил дотичної

Похідна показує, як швидко змінюється функція в точці; геометрично — нахил дотичної до графіка. За означенням беруть нахил хорди через дві близькі точки і зменшують відстань h між ними:

f′(x) = limh→0 (f(x + h) − f(x)) / h
h = нахил хорди · точна похідна −0,189

Завдання: зменшуйте h. Як змінюється нахил хорди? У скільки разів зменшується різниця з точним значенням, якщо h зменшити в 10 разів?

Різницева формула — це нахил хорди з малим, але ненульовим h. Тобто означення похідної без границі.

4. Різницеві формули на графіку

Кожна різницева формула відповідає кривій через кілька точок функції навколо x і повертає нахил цієї кривої в точці x. Що більше точок, то ближче крива до функції — і то ближче нахил до точної похідної.

У центральній і п'ятиточковій формулах середня точка f(x) входить з коефіцієнтом 0: крива через неї проходить, але обчислювати f(x) не потрібно (на графіку — порожній кружок). Тому df/dx1 бере 2 значення f, df/dx2 — 4. (У літературі df/dx2 називають «п'ятиточковою» формулою — за кількістю точок кривої.)

h = точна похідна −0,189

Завдання: при h = 2 порівняйте три формули на графіку. Яка крива найближче до f(x) поблизу x = 0? Зменшуйте h — що відбувається з усіма трьома?

Оптимальний h — дно «ями», де похибка найменша. У зразку: 10−5 для df/dx1 і 10−3 для df/dx2. Для df/dx2 оптимум більший, бо похибка формули в неї зменшується швидше і похибка заокруглення починає переважати раніше.

6. Квадратурні формули інтеграла

Для обчислення інтеграла на відрізку [u; v] програма ділить його на N рівних частин з кроком h = (v − u) / N і використовує дві квадратурні формули:

S1 (трапеції) = h · ((f(u) − f(v)) / 2 + Σi=1..N f(u + i·h))
S2 (Сімпсон) = (h / 3) · ((f(u) − f(v)) + Σi=1..N/2 (4·f(u + (2i − 1)·h) + 2·f(u + 2i·h)))

u = 0, v = 10000 (замість ∞), N = 10; 100; …; 107. Для формули Сімпсона N має бути парним.

Мінус f(v) не є помилкою: сума до N уже містить f(v). Після перетворення це звичні формули з методички: трапеції (h/2)(y0 + 2y1 + … + 2yN−1 + yN), Сімпсон (h/3)(y0 + 4y1 + 2y2 + … + 4yN−1 + yN).

Що таке інтеграл: площа під кривою

Визначений інтеграл — площа під графіком між межами. Фізично — накопичена величина: швидкість → шлях, витрата → об'єм. Відрізок розбивають на смужки ширини h і додають їхні площі:

∫ ≈ h · (f(x1) + f(x2) + … + f(xn))
h = сума · точна площа 5,291

Похідна — відношення різниць (ділення на h), інтеграл — сума (множення на h).

8. Похибка інтеграла залежно від кількості інтервалів N

Замалий N

При N = 10 крок h = 1000, а функція помітно відмінна від нуля лише до x ≈ 20…30. Уся крива потрапляє в першу смужку: трапеція з висотами f(0) = 1 і f(1000) ≈ 0 має площу 1000 · (1 + 0) / 2 = 500 замість 5,291. Формула «не бачить» кривої — крок більший за саму криву.

Тому важливий не сам крок h, а k · h — скільки кроків припадає на ділянку спаду кривої (≈ 1/k). Що більше k, то швидше спадає функція і то більше N потрібно для тієї самої точності.

Достатній N

Коли крок малий порівняно з кривою, похибка зменшується з кожним десятикратним збільшенням N: у методу трапецій — приблизно в 100 разів, у методу Сімпсона — приблизно в 104 разів.

Чому немає «ями», як у похідної

Похідна віднімає майже рівні числа і ділить на малий h — похибка заокруглення підсилюється. Інтеграл додає значення і множить на малий h — заокруглення не підсилюється. Лише при N = 107 у методу Сімпсона помітне накопичення заокруглень від мільйонів доданків, але на рівні 10−11 %.

Завдання: перевірте свою програму на відрізку [0; 10], де f(v) ≠ 0. Точне значення: (A / k) · (1 − e−10k). Чи збігається результат при великому N?

11. Аналітично чи чисельно

Результатформула, з неї точне числонаближене число в точці
Спосібтаблиця похідних і правилазначення f у кількох точках
Потрібно знатиформулу fлише як обчислити f(x)
  • Похідну функції, записаної формулою з елементарних (поліноми, ex, sin, ln), можна знайти аналітично завжди.
  • Первісну — не завжди: для e−x² чи sin(x)/x її не записати формулою, такі інтеграли обчислюють лише чисельно.
  • Для функції, заданої таблицею чи програмою, — тільки чисельно.

Для функції цієї роботи відомі обидві відповіді — тому можна виміряти похибку чисельних методів.

12. Точні значення (п. 2 звіту)

Похідна

(ea·x)′ = a · ea·x, тут a = −k:

f′(x) = −A · k · e−k·x → f′(0) = −A · k

Зразок: f′(0) = −1 · 0,189 = −0,189. Перевірка: функція спадає — похідна від'ємна ✓

Інтеграл

F(x) = −(A / k) · e−k·x · перевірка: F′(x) = A · e−k·x = f(x) ✓
∫0∞ f(x) dx = F(∞) − F(0) = 0 − (−A / k) = A / k

Зразок: 1 / 0,189 = 5,291005291005291.

Чому в програмі ∞ замінено на 10000. Площа «хвоста» за межею дорівнює (A / k) · e−k·10000. У зразку це e−1890 — у комп'ютері точно 0; навіть для k = 0,01 — близько 10−42. Для цих функцій 10000 фактично є нескінченністю.

Висновки

  • Різницеві й квадратурні формули замінюють функцію поблизу вузлів прямою чи параболою і беруть нахил (похідна) або площу (інтеграл) уже цієї кривої.
  • Похибка похідної має «яму»: при великому h переважає похибка формули, при малому — похибка заокруглення. Оптимальний крок визначають за власними результатами.
  • Похибка інтеграла зменшується зі збільшенням N; заокруглення майже не заважає, бо значення додаються, а не віднімаються.
  • Крок має бути малим порівняно з ділянкою, на якій змінюється функція; інакше результат хибний (N = 10 → 500 замість 5,291).
  • Формули, що використовують більше точок (df/dx2, Сімпсон), точніші при тому самому кроці.

Додаткова задача. Чи перевищив водій швидкість?

Автомобіль котиться з вимкненим двигуном, GPS записує його координату x кожні 0,5 с. У момент t = 3 с автомобіль проїжджає знак обмеження 50 км/год. Чи порушив водій правила?

Завдання

  1. За таблицею обчисліть швидкість у момент t = 3 с двома способами для h = 0,5; 1; 2 с: «на наступному відрізку» (x(3 + h) − x(3)) / h і центральною формулою (x(3 + h) − x(3 − h)) / (2h). Переведіть у км/год (× 3,6).
  2. Чи перевищив водій 50 км/год? Чи однакову відповідь дають обидва способи при всіх h?
  3. Відомо, що координата змінюється за законом x(t) = (v0 / k) · (1 − e−k·t), v0 = 20 м/с, k = 0,1 с−1. Знайдіть точну швидкість v(3) як похідну і порівняйте. Який спосіб надійніший і чому?

Спосіб «на наступному відрізку» — це середня швидкість на ділянці після знака, а не швидкість у момент проїзду. Автомобіль гальмує, тому середня швидкість після знака менша за миттєву. Центральна формула бере точки симетрично з обох боків — помилки зліва і справа майже компенсуються.
