Лабораторна робота № 3 · Чисельні методи

Чисельне визначення похідної та інтеграла

Усі приклади побудовано на функції зразка звіту. Для свого варіанта підставте власні A і k.

1. Функція

У кожному варіанті функцію задано формулою

f(x) = A · e−k·x

A залежить від групи, k — від номера варіанта. У зразку A = 1, k = 0,189: f(x) = e−0,189x.

Це показникова функція y = A · ax (a > 0, a ≠ 1): змінна x стоїть у показнику степеня. Оскільки e−kx = (e−k)x, основа a = e−k < 1, тому функція спадає.

Множина значень(0; +∞) — завжди додатна, нуля не досягає
Значення в x = 0A (бо a0 = 1)
Зразокa = e−0,189 = 0,8278: на кожній одиниці x значення зменшується на ≈ 17 %

2. Завдання

  1. Похідна в точці x = 0 — швидкість зміни функції на початку.
  2. Інтеграл від 0 до ∞ — площа під усією кривою.

Кожну величину визначають двічі: аналітично (точне значення за формулами) і чисельно (програмою, лише за значеннями f у точках). Порівняння показує похибку чисельного методу.

На практиці формули часто немає: є записи датчика або програма, що обчислює f(x). Тут формулу відомо навмисно — щоб виміряти похибку.

3. Похідна — нахил дотичної

Похідна показує, як швидко змінюється функція в точці. Геометрично — нахил дотичної до графіка. За означенням беруть нахил хорди через дві близькі точки і зменшують відстань h між ними:

f′(x) = limh→0 (f(x + h) − f(x)) / h
h = нахил хорди · точна похідна −0,189

Завдання: зменшуйте h. Як змінюється нахил хорди? У скільки разів зменшується різниця з точним значенням, якщо h зменшити в 10 разів?

Чисельна похідна — це нахил хорди з малим, але ненульовим h.

4. Інтеграл — площа під кривою

Визначений інтеграл — площа під графіком між межами. Фізично — накопичена величина: швидкість → шлях, витрата → об'єм. Відрізок розбивають на смужки ширини h і додають їхні площі:

∫ ≈ h · (f(x1) + f(x2) + … + f(xn))
h = сума · точна площа 5,291

Завдання: встановіть h = 1 і оберіть трапеції. Порівняйте результат із рядком N = 10000 у таблиці інтеграла зразка звіту.

Похідна — це відношення різниць (ділення на h), інтеграл — сума (множення на h). Чисельні методи роблять саме це з малим h.

5. Аналітично чи чисельно

АналітичноЧисельно
Результатформула, з неї точне числонаближене число в точці
Спосібтаблиця похідних і правилазначення f у кількох точках

  • Похідну функції, записаної формулою з елементарних (поліноми, ex, sin, ln), можна знайти аналітично завжди.
  • Первісну — не завжди: для e−x² чи sin(x)/x її не записати формулою, такі інтеграли обчислюють лише чисельно.
  • Для функції, заданої таблицею чи програмою, — тільки чисельно.

Для функції цієї роботи відомі обидві відповіді — тому можна виміряти похибку чисельних методів.

6. Точні значення (п. 2 звіту)

Похідна

(ea·x)′ = a · ea·x, тут a = −k:

f′(x) = −A · k · e−k·x → f′(0) = −A · k

Зразок: f′(0) = −1 · 0,189 = −0,189. Перевірка: функція спадає — похідна від'ємна ✓

Інтеграл

F(x) = −(A / k) · e−k·x · перевірка: F′(x) = A · e−k·x = f(x) ✓
∫0∞ f(x) dx = F(∞) − F(0) = 0 − (−A / k) = A / k

Зразок: 1 / 0,189 = 5,291005291005291.

Чому в програмі ∞ замінено на 10000. Площа «хвоста» за межею дорівнює (A / k) · e−k·10000. У зразку це e−1890 — у комп'ютері точно 0; навіть для k = 0,01 — близько 10−42. Для цих функцій 10000 фактично є нескінченністю.

7. Різницеві формули похідної

Різницева формула наближено обчислює похідну в точці через значення функції в кількох сусідніх точках, віддалених на крок h. Це означення похідної без границі: h мале, але не нульове.

ФормулаТочкиПорядокУ звіті
(f(x+h) − f(x)) / hx, x+h1— (для порівняння)
(f(x+h) − f(x−h)) / (2h)x−h, x+h2df/dx1
(−f(x+2h) + 8f(x+h) − 8f(x−h) + f(x−2h)) / (12h)x−2h … x+2h4df/dx2

Обидві формули роботи — центральні: точки беруться симетрично з обох боків від x. Тому програма обчислює f і при x < 0.

Порядок формули

Похибка формули порядку p пропорційна hp: якщо h зменшити в 10 разів, похибка зменшиться в 10p разів. Відносна похибка на функції зразка:

hпорядок 1порядок 2порядок 4

0,010,0944 %5,95·10⁻⁵ %4,39·10⁻¹¹ %

h ÷ 10 → похибка ÷ 10, ÷ 100, ÷ 10 000 відповідно. Формула вищого порядку точніша при тому самому h, але обчислює f у більшій кількості точок.

8. Від полінома Лагранжа до різницевої формули

Ідея (зв'язок із лабораторною роботою № 2): похідну функції замінюють похідною інтерполяційного полінома, що проходить через її точки поблизу x.

h = нахил дотичної до L2 · точна похідна −0,189

Центральна формула — з L2

Для зручності x = 0. Три точки з кроком h:

x−h0h
yy₋y₀y₊

1. Поліном Лагранжа через ці точки:

L2(x) = y₋·(x − 0)(x − h) / ((−h − 0)(−h − h)) + y₀·(x + h)(x − h) / ((0 + h)(0 − h)) + y₊·(x + h)(x − 0) / ((h + h)(h − 0))

2. Знаменники: (−h)(−2h) = 2h², (h)(−h) = −h², (2h)(h) = 2h². Після розкриття дужок:

L2(x) = y₋·(x² − h·x) / (2h²) − y₀·(x² − h²) / h² + y₊·(x² + h·x) / (2h²)

3. Похідна за x (h — стале число):

L2′(x) = y₋·(2x − h) / (2h²) − y₀·2x / h² + y₊·(2x + h) / (2h²)

4. Підстановка x = 0:

L2′(0) = y₋·(−h) / (2h²) − 0 + y₊·h / (2h²) = (y₊ − y₋) / (2h)

Отримано центральну формулу (f(x + h) − f(x − h)) / (2h). Середня точка y₀ скоротилася, тому у формулі лише дві точки.

Перевірка на зразку, h = 1: y₋ = f(−1) = 1,2080, y₊ = f(1) = 0,8278 → (0,8278 − 1,2080) / 2 = −0,19013 — збігається з таблицею звіту при h = 1.

П'ятиточкова формула — з L4

Аналогічно, через п'ять точок −2h, −h, 0, h, 2h. Похідна кожного доданка Лагранжа в x = 0 дорівнює y цієї точки, помноженому на коефіцієнт:

точка−2h−h0h2h
коефіцієнт × 1/(12h)1−808−1
L4′(0) = (y₋₂ − 8y₋₁ + 8y₁ − y₂) / (12h)

Перевірка коефіцієнта точки h: доданок Лагранжа y₁·(x + 2h)(x + h)(x − 0)(x − 2h) / ((3h)(2h)(h)(−h)). Похідна в x = 0 дорівнює добутку решти дужок у нулі: y₁·(2h)(h)(−2h) / (−6h⁴) = y₁·8 / (12h).

Що більше точок, то точніше поліном повторює функцію поблизу x і то вищий порядок формули: 3 точки → порядок 2, 5 точок → порядок 4.
