Лабораторна робота № 4 · Чисельні методи

Чисельне розв'язування системи лінійних алгебраїчних рівнянь

Усі приклади побудовано на системі зразка звіту. Свою систему розв'язуйте власною програмою.

1. Система рівнянь

Система з 5 лінійних рівнянь з 5 невідомими. Треба знайти значення, що задовольняють усі рівняння одночасно. Лінійні — змінні лише в першому степені, помножені на числа.

Розв'язок зразка: a = b = c = d = e = 3. Матрична форма A·x = B — ті самі числа: коефіцієнти в матриці A, праві частини у стовпці B.

Скільки розв'язків

Для двох рівнянь із двома невідомими кожне рівняння — пряма, розв'язок — точка перетину.

Для 5 змінних — те саме в 5-вимірному просторі. Якщо визначник det A ≠ 0, розв'язок рівно один (у зразку det A = 10,02).

2. Метод Гауса

Шкільне виключення змінних, записане як алгоритм:

  1. Прямий хід. Змінні по черзі. Щоб прибрати змінну з рядка, від нього віднімають рядок-інструмент, помножений на m = (коефіцієнт змінної в рядку) / (коефіцієнт змінної в інструменті). Множиться все рівняння — коефіцієнти і права частина; інструмент не змінюється.
  2. Вибір інструмента. Серед ще не оброблених рядків беруть той, де коефіцієнт змінної найбільший за модулем, і ставлять його на поточне місце. Так не ділять на нуль і не підсилюють похибку заокруглення.
  3. Зворотний хід. В останньому рядку лишається одна змінна; її знаходять і підставляють у рядки вище.

3. Метод Гауса — Зейделя

Ітераційний метод: з кожного рівняння виражають «свою» змінну і уточнюють наближення по колу.

a = 15 − b − c − d − e
b = (−1,5 + 0,5a + 0,9c + 0,1d + 0,8e) / 1,8
c = (3,6 + 0,3b + 0,6d + 0,4e) / 2,5
d = (−0,9 + 0,9b + 0,8c) / 1,4
e = (1,5 + 0,5b + 0,5d) / 1,5
  1. Початкове наближення — усі нулі.
  2. Ітерація: перераховують a, b, c, d, e по черзі, одразу підставляючи щойно отримані значення.
  3. Зупинка: коли найбільша зміна змінної за ітерацію (абсолютна й відносна) менша за δ = 10−10. Перевіряється не похибка, а зміна — точної відповіді програма не знає.
показано ітерацій: найбільша зміна за останню ітерацію

Значення коливаються навколо 3 і наближаються до нього: похибка зменшується приблизно в 2,7 раза за ітерацію. У зразку зупинка — на 27-й ітерації.

4. Чи завжди Зейдель збігається? Діагональна перевага

Діагональна перевага: у кожному рівнянні |коефіцієнт «своєї» змінної| більший за суму модулів решти коефіцієнтів. Тоді похибки інших змінних діляться на великий коефіцієнт і гаснуть — метод збігається. Без переваги похибка може зростати — метод розходиться. Умова достатня, але не обов'язкова: у зразку перевага є лише в рядках 3 і 5, а метод збігся.

Приклад: та сама система з двох рівнянь у різному порядку (розв'язок x = 1, y = 1).

Перестановка рівнянь не змінює розв'язок, але змінює, з якого рівняння виражається кожна змінна. Якщо Зейдель розійшовся — це нормальний результат роботи: його треба помітити (порівняти з Гаусом) і пояснити.

Для системи з мільйоном невідомих (моделювання міцності, теплопровідності) метод Гауса потребує близько 7·1017 операцій — роки роботи комп'ютера, а Зейдель — секунди. Для 5×5 краще Гаус; Зейдель у роботі — щоб побачити ітераційний метод і його збіжність.

Висновки

  • Метод Гауса — виключення змінних: прямий хід дає трикутну систему, зворотний — розв'язок. Працює завжди, якщо det A ≠ 0.
  • Метод Гауса — Зейделя уточнює наближення по колу і зупиняється, коли зміна стає меншою за δ.
  • Зейдель збігається не завжди: усе залежить від матриці (діагональна перевага). Результат ітераційного методу треба перевіряти.
